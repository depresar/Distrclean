# Дистрклин — сайт

Умная химия. Эффективные решения.
Снижаем расходы на профессиональную химию до 30% за счёт умных автоматизированных технологий и систем дозирования.

## Как посмотреть
Откройте `index.html` в браузере (двойной клик). Или запустите локальный сервер:

```bash
python3 -m http.server 8000
```
и откройте http://localhost:8000

## Структура
| Путь | Что там |
|---|---|
| `index.html` | Главная страница |
| `catalog.html` | Каталог: 93 товара, фильтр по разделам, поиск, окно товара |
| `css/style.css` | Все стили. Цвета и размеры — в начале файла (`:root`) |
| `js/main.js` | Скрипты: видео, вкладки отраслей, анимация цифр, форма, слайдер |
| `js/products.js` | Список товаров и разделов каталога (название, описание, цена, фото) |
| `js/catalog.js` | Логика страницы каталога |
| `js/search.js` | Поиск в шапке: подсказки и список того, что ищется (массив `INDEX`) |
| `assets/img/logo.svg` | Логотип (вектор), `logo-white.svg` — для тёмного фона |
| `assets/img/catalog/` | Фото разделов каталога |
| `assets/img/partners/` | Логотипы партнёров |
| `assets/img/products/` | Фото товаров (WebP): `имя.webp` — крупно, `имя-sm.webp` — превью |
| `assets/img/certificates/` | Сертификаты: `имя.jpg` (крупно) и `имя-sm.jpg` (превью) |
| `assets/video/` | Сжатые видео для сайта + постеры (.jpg) |
| `assets/pdf/` | PDF-каталоги Novelhim 2025, Novelhim HoReCa 2026, Seko 2026 (сжатые) |
| `_source/` | Исходники: оригинальные видео, скриншоты старого сайта, логотип |

## Тексты отраслей
